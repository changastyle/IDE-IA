Prompt: dime de que va este proyecto
Respuesta: Es un juego clásico de **Snake (la serpiente)** hecho con HTML5 Canvas y JavaScript vanilla, sin librerías externas.

**Lo que incluye:**

- 🎮 **Juego principal** (`index.html` / `snake.html` + `snake.js`): tablero de 20×20, la serpiente se mueve con las flechas del teclado o swipe táctil, come comida para crecer y suma puntos. Tiene récord guardado en `localStorage`, overlay de Game Over con botón de reinicio, y niveles de velocidad.
- 🔊 **Efectos de sonido** (`audio/sound.js`): generados con Web Audio API (sin archivos de audio externos) — suena al comer, al comer comida dorada, al subir de nivel y en el Game Over.
- 🗺️ **Editor de niveles** (`html/editor-de-mapas.html` + `js/editor.js`): una herramienta para dibujar tus propios muros en la cuadrícula (clic para pintar, clic derecho para borrar). Los niveles se guardan en el navegador y luego puedes jugarlos desde el juego principal, donde chocar con un muro te elimina.
- 🎨 **Estilos** (`styles.css`): interfaz con HUD de puntuación/récord/nivel, diseño responsive para móvil.

En resumen: un Snake completo con sonido, récords persistentes y la posibilidad de crear y jugar niveles personalizados con muros.
