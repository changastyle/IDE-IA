- 🎨 **Estilos** (`styles.css`): interfaz con HUD de puntuación/récord/nivel, diseño responsive para móvil.

En resumen: un Snake completo con sonido, récords persistentes y la posibilidad de crear y jugar niveles personalizados con muros.

Respuesta: La **idea 3** de `changes.md` es: **"Niveles de velocidad visibles: mostrar un aviso breve '¡Nivel 2!' al subir de velocidad"**. Te la desarrollo aquí 👇

## 🎯 El problema que resuelve

Hoy, cuando la puntuación cruza un múltiplo de 50, `checkLevel()` en `snake.js` sube el nivel silenciosamente:

```js
function checkLevel() {
    const newLevel = Math.floor(score / 50) + 1;
    if (newLevel > level) {
        level = newLevel;
        if (window.SnakeSound) SnakeSound.levelUp();  // suena, pero...
    }
}
```

Suena el efecto `levelUp()`, pero **visualmente no pasa nada**: el único indicio es que el número del HUD cambia y la serpiente empieza a moverse más rápido de golpe. El jugador puede no entender por qué de repente va todo más rápido.

## 🛠️ Cómo se implementaría

**1. Aviso flotante en el canvas** (lo más simple, sin tocar el HTML):

- Añadir una variable `levelBanner = { text, life }`.
- En `checkLevel()`, al subir de nivel: `levelBanner = { text: '¡Nivel ' + level + '!', life: 1.5 }`.
- En `draw()`, si `levelBanner.life > 0`, dibujar el texto centrado con `globalAlpha` proporcional a `life` (se desvanece solo) y una fuente grande con borde/glow verde.
- En `loop()` o `updateParticles()`, decrementar `life` con el delta de tiempo.

**2. Detalles de pulido opcionales:**

- **Animación de escala**: que el texto aparezca grande y se encoja levemente (efecto "pop").
- **Flash sutil del borde del canvas** en verde durante medio segundo.
- **Mostrar también la nueva velocidad**: "¡Nivel 3! ⚡ Más rápido".
- **Sonido ya existe**: `SnakeSound.levelUp()` se mantiene como está.

**3. Alternativa con DOM** (más accesible): un `<div id="levelBanner">` sobre el `#game-container`, con una animación CSS (`@keyframes` de fade-in/out) que se activa añadiendo una clase y se quita con `animationend`. Ventaja: no interfiere con el render del canvas y es más fácil de estilizar.

## ⚖️ Esfuerzo vs impacto

- **Esfuerzo**: bajo (~20-30 líneas en total, un solo archivo si se hace en canvas).
- **Impacto**: alto en sensación de progreso — es uno de esos detalles que hacen que el juego se sienta "vivo" y le da al jugador una recompensa visual cada 50 puntos.

¿Querés que lo implemente directamente en `snake.js` (versión canvas) o prefieres la variante con DOM/CSS?
