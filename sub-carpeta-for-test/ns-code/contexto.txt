# Contexto del proyecto

## Audio
- Carpeta `audio/` con `sound.js`: efectos generados con Web Audio API (sin archivos externos).
- API global: `window.SnakeSound` con `eat()`, `gold()`, `gameOver()`, `levelUp()`.
- `snake.js` llama a estos sonidos al comer, comer comida dorada, subir de nivel y en Game Over.
- `index.html` y `snake.html` cargan `audio/sound.js` antes de `snake.js`.

## Editor de niveles
- `editor.html` + `editor.js`: editor de niveles con cuadrícula 20×20. Se pinta/borra muros con clic o arrastre (clic derecho borra).
- Los niveles se guardan en `localStorage` con claves `snake_custom_level_N` (N = número del nivel, desde 2).
- El nivel a jugar se selecciona con la clave `snake_selected_level` ('classic' o el número).
- `snake.js` carga los muros del nivel seleccionado al arrancar: colisión con muro = Game Over, la comida no aparece sobre muros, y los muros sobre la posición inicial de la serpiente (fila 10, x 8–12) se eliminan automáticamente.
- El HUD muestra "Nivel N" cuando se juega un nivel personalizado.
- Enlaces al editor añadidos en el footer de `index.html` y `snake.html`, y enlace de vuelta al juego en `editor.html`.

## Reorganización de carpetas
- Nueva estructura: `html/` (páginas) y `js/` (scripts del editor).
- `html/editor-de-mapas.html` es el editor nuevo; carga `/js/editor.js` y `/styles.css`.
- `server.js` sirve `/editor-de-mapas.html` (y `/editor.html`) desde `html/editor-de-mapas.html`.
- `index.html` y `snake.html` enlazan al editor con `/editor-de-mapas.html`.
- `js/editor.js` redirige a `/index.html` y usa `history.replaceState` con `/editor-de-mapas.html`.
